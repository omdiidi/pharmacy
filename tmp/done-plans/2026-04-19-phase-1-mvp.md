**What runs where in Phase 1:**
- **Render web service**: Next.js app (UI + chatbot API). Deploys from main branch.
- **Render worker service**: minicrew worker stub provisioned (no jobs run in Phase 1; activated in Phase 2 when minicrew runtime lands). `config.yaml` + skill files are authored.
- **Supabase**: Everything persistent. Provides Realtime channel for Inbox updates (Phase 2).
- **Backblaze B2 (separate cloud account)**: Off-cloud encrypted backup target. Render Cron writes weekly.

**Chatbot tool loop:**

```
user message → POST /api/chat
  → Claude API call with { system: CoS prompt + context, tools, messages }
  → stream response chunks to client
  → if Claude invokes tool:
      → execute tool handler (Supabase query)
      → return tool_result to Claude
      → continue loop until stop_reason = "end_turn"
  → client renders final message
```

## Key Pseudocode

### Chatbot API with Claude + tool loop + prompt caching + real streaming

```typescript
// app/api/chat/route.ts
import Anthropic from '@anthropic-ai/sdk';
import { toolDefinitions, executeTool } from '@/lib/tools';
import { buildSystemPrompt } from '@/lib/system-prompt';
import { requireAuthenticatedUser } from '@/lib/auth';
import { checkRateLimit } from '@/lib/rate-limit';

const MAX_TOOL_ITERATIONS = 8;
const MAX_REQUEST_INPUT_TOKENS = 150_000;  // stop runaway conversations

const anthropic = new Anthropic({ apiKey: process.env.ANTHROPIC_API_KEY! });

export async function POST(req: Request) {
  // 1. Auth gate — Supabase Auth magic link + allowlist re-check + pharmacy mapping
  const session = await requireAuthenticatedUser(req);
  if (!session) return new Response('Unauthorized', { status: 401 });

  // 2. Rate limit per user (Supabase-table-backed sliding window, NOT in-memory — Render may run multiple workers)
  const rl = await checkRateLimit(session.userId, { window: 60_000, max: 60 });
  if (!rl.ok) return new Response('Rate limited', { status: 429, headers: { 'Retry-After': String(rl.retryAfterSeconds) } });

  // 3. Daily budget guard — reject if today's cumulative spend for this user exceeds cap
  const todaySpend = await getTodayClaudeSpendUsd(session.userId);
  if (todaySpend >= MAX_DAILY_CLAUDE_SPEND_USD) {
    return new Response('daily budget exceeded', { status: 429 });
  }

  const { messages } = await req.json();
  const systemBlocks = await buildSystemPrompt(session);

  const encoder = new TextEncoder();
  const stream = new ReadableStream({
    async start(controller) {
      try {
        let conversation = messages;
        let iterations = 0;
        let approxInputTokens = 0;  // track locally; only call countTokens on material growth

        // One up-front token count on initial conversation
        const initialCount = await anthropic.messages.countTokens({
          model: 'claude-opus-4-7',
          system: systemBlocks,
          tools: toolDefinitions,
          messages: conversation,
        });
        approxInputTokens = initialCount.input_tokens;
        if (approxInputTokens > MAX_REQUEST_INPUT_TOKENS) {
          controller.enqueue(encoder.encode(JSON.stringify({ type: 'error', value: 'conversation too long' }) + '\n'));
          controller.close();
          return;
        }

        while (iterations < MAX_TOOL_ITERATIONS) {
          iterations++;

          // Real SSE streaming from Anthropic (prompt caching is GA — no beta header needed)
          // AbortSignal wired so Render pod recycling cleanly cancels in-flight streams
          const claudeStream = anthropic.messages.stream({
            model: 'claude-opus-4-7',  // verified by scripts/verify-models.ts at predeploy
            max_tokens: 4096,
            system: systemBlocks,
            tools: toolDefinitions,
            messages: conversation,
          }, { signal: req.signal });

          // Forward content_block_delta events as NDJSON tokens
          for await (const event of claudeStream) {
            if (event.type === 'content_block_delta' && event.delta.type === 'text_delta') {
              controller.enqueue(encoder.encode(JSON.stringify({ type: 'text_delta', value: event.delta.text }) + '\n'));
            } else if (event.type === 'content_block_start' && event.content_block.type === 'tool_use') {
              controller.enqueue(encoder.encode(JSON.stringify({ type: 'tool_use_start', name: event.content_block.name, id: event.content_block.id }) + '\n'));
            }
          }

          const finalMessage = await claudeStream.finalMessage();

          // Record usage for budget tracking
          await recordClaudeUsage(session.userId, finalMessage);

          if (finalMessage.stop_reason !== 'tool_use') break;

          // Execute tool calls — pharmacyId threaded through for multi-tenant safety
          const toolResults = await Promise.all(
            finalMessage.content
              .filter((b): b is Anthropic.ToolUseBlock => b.type === 'tool_use')
              .map(async (b) => ({
                type: 'tool_result' as const,
                tool_use_id: b.id,
                content: await executeTool(b.name, b.input, { pharmacyId: session.pharmacyId }),
              }))
          );
          conversation = [
            ...conversation,
            { role: 'assistant', content: finalMessage.content },
            { role: 'user', content: toolResults },
          ];

          // Only re-count tokens when tool results appended significant content (> 10kb approx)
          const appendedBytes = JSON.stringify(toolResults).length;
          if (appendedBytes > 10_000) {
            const recount = await anthropic.messages.countTokens({
              model: 'claude-opus-4-7',
              system: systemBlocks,
              tools: toolDefinitions,
              messages: conversation,
            });
            approxInputTokens = recount.input_tokens;
            if (approxInputTokens > MAX_REQUEST_INPUT_TOKENS) {
              controller.enqueue(encoder.encode(JSON.stringify({ type: 'error', value: 'conversation grew past token budget' }) + '\n'));
              break;
            }
          }
        }

        if (iterations >= MAX_TOOL_ITERATIONS) {
          controller.enqueue(encoder.encode(JSON.stringify({ type: 'error', value: 'max tool iterations reached' }) + '\n'));
        }

        controller.close();
      } catch (err) {
        controller.enqueue(encoder.encode(JSON.stringify({ type: 'error', value: String(err) }) + '\n'));
        controller.close();
      }
    },
  });

### Auth + pharmacy_id threading (the multi-tenant boundary)

```typescript
// lib/auth.ts
import { createClient } from '@/lib/supabase/server';

const ALLOWED_EMAILS = (process.env.ALLOWED_USER_EMAILS ?? '')
  .split(',')
  .map((e) => e.trim().toLowerCase())
  .filter(Boolean);

export type SessionContext = { userId: string; email: string; pharmacyId: string };

export async function requireAuthenticatedUser(req: Request): Promise<SessionContext | null> {
  const supabase = createClient();
  const { data: { user } } = await supabase.auth.getUser();
  if (!user) return null;

  // Re-check allowlist on every request (not just at magic-link callback) — revocation needs to work
  const email = user.email?.toLowerCase();
  if (!email || !ALLOWED_EMAILS.includes(email)) return null;

  // Map user → pharmacy via user_pharmacy_access (one row per (user_id, pharmacy_id) pair)
  const { data: access, error } = await supabase
    .from('user_pharmacy_access')
    .select('pharmacy_id')
    .eq('user_id', user.id)
    .single();
  if (error || !access) return null;

  return { userId: user.id, email, pharmacyId: access.pharmacy_id };
}

### Tool handler pattern (safe query, Zod-validated input, no PostgREST `or=` injection)

```typescript
// lib/tools/query_products.ts
import { createClient } from '@/lib/supabase/server';
import { z } from 'zod';
import type Anthropic from '@anthropic-ai/sdk';

// Reject characters that break PostgREST `or=` parsing OR inject ilike wildcards we don't intend
const SAFE_QUERY = /^[A-Za-z0-9 \-_.+/]+$/;

const InputSchema = z.object({
  query: z.string().min(1).max(100).regex(SAFE_QUERY, 'Query contains disallowed characters'),
  limit: z.number().int().min(1).max(100).default(20),
});

export const query_products_def: Anthropic.Tool = {
  name: 'query_products',
  description: 'Search the pharmacy catalog. Use this when Kaleem asks about specific products by name, NDC, UPC, ASIN, brand, or category.',
  input_schema: {
    type: 'object',
    properties: {
      query: { type: 'string', description: 'Search term — name, brand, category, NDC, UPC, or ASIN' },
      limit: { type: 'number', description: 'Max rows to return', default: 20 },
    },
    required: ['query'],
  },
};

// Escape LIKE metacharacters so user input can't match wildcards we didn't intend
function escapeLike(s: string): string {
  return s.replace(/[\\%_]/g, (c) => '\\' + c);
}

export async function query_products(rawInput: unknown, ctx: { pharmacyId: string }): Promise<string> {
  const parsed = InputSchema.safeParse(rawInput);
  if (!parsed.success) return JSON.stringify({ error: parsed.error.message });
  const { query, limit } = parsed.data;

  const supabase = createClient();
  const cols = 'id, name, brand, category, asin, ndc, upc, default_supplier, last_listed_price, last_listed_at, watchlist_status';
  const like = `%${escapeLike(query)}%`;

  // Five parallel queries, all using parameterized PostgREST methods. No string composition into `.or()`.
  const [byAsin, byNdc, byUpc, byName, byBrand, byCategory] = await Promise.all([
    supabase.from('products').select(cols).eq('pharmacy_id', ctx.pharmacyId).eq('asin', query).limit(limit),
    supabase.from('products').select(cols).eq('pharmacy_id', ctx.pharmacyId).eq('ndc', query).limit(limit),
    supabase.from('products').select(cols).eq('pharmacy_id', ctx.pharmacyId).eq('upc', query).limit(limit),
    supabase.from('products').select(cols).eq('pharmacy_id', ctx.pharmacyId).ilike('name', like).limit(limit),
    supabase.from('products').select(cols).eq('pharmacy_id', ctx.pharmacyId).ilike('brand', like).limit(limit),
    supabase.from('products').select(cols).eq('pharmacy_id', ctx.pharmacyId).ilike('category', like).limit(limit),
  ]);

  // Fail loud if any parameterized call errored
  for (const r of [byAsin, byNdc, byUpc, byName, byBrand, byCategory]) {
    if (r.error) return JSON.stringify({ error: r.error.message });
  }

  // De-dupe by id, exact matches first, then ilike results
  const byId = new Map<string, any>();
  for (const r of [byAsin.data, byNdc.data, byUpc.data, byName.data, byBrand.data, byCategory.data]) {
    for (const row of r ?? []) byId.set(row.id, row);
  }
  const rows = Array.from(byId.values()).slice(0, limit);
  return JSON.stringify({ rows, count: rows.length });
}
```

  pharmacy uuid,
  kind_filter text default null,
  k int default 10
)
returns table (
  id uuid,
  kind memory_kind,
  content text,
  metadata jsonb,
  importance numeric,
  rank float
)
language sql stable
as $$
  select
    m.id, m.kind, m.content, m.metadata, m.importance,
    similarity(m.content, q) as rank
  from memory m
  where m.pharmacy_id = pharmacy
    and (kind_filter is null or m.kind::text = kind_filter)
    and m.content % q    -- trigram %% operator (uses gin index)
  order by rank desc
  limit k;

### Agent skill prompt structure (example: Research Analyst)

```markdown
<!-- minicrew-config/skills/research-analyst.md -->

# Research Analyst Skill

You are the Research Analyst for Kaleem's pharmacy OTC arbitrage operation. Your job is to produce the morning briefing: which products should he list today, at what price, with what confidence, and why.

## Inputs you will receive (via job payload)
- `category_group`: the category archetype for this fan-out run (allergy / immune_cold_flu / etc.)
- `date`: today's date
- `previous_analysis_ids`: briefing IDs from the last 7 days (for continuity)

## Your process

1. **Gather current signals**
   - Query Supabase `signals` table for latest Keepa, FDA shortage, Google Trends data in this category group
   - Query `wholesaler_stock_snapshots` for supply state across sources
   - Query `orders` for Kaleem's own sales history in this category (30/90/365 day)

2. **Retrieve relevant memory**
   - `search_memory` with query "arbitrage signals in {category_group}" — procedural playbooks
   - Relevant semantic memory (brand-hunt list, wholesaler reliability)
   - Kaleem's preferences

3. **Apply policy filter** (Tier 0 auto-excludes from `policy_rules` table)
   - Block: pseudoephedrine, ephedrine, kratom, CBD, lidocaine >4/5%, DEA-scheduled, Transparency w/o codes, FDA-recalled
   - Flag: TIC-missing supplements, brand-hunt list (needs LOA)

4. **Score candidates**
   - Compute FBM-competitive score (FBA-empty or FBM-dominant win)
   - Compute scarcity score (offer count drop ≥30%, FBA→FBM flip, Amazon-out flag)
   - Compute margin after Amazon fees + shipping + COGS from cheapest wholesaler
   - Compute Fair Pricing ceiling (30d BB median × 1.25)
   - Combine into 0-100 opportunity score

5. **Also run LLM web search** (Perplexity-style) for the category group
   - "best-selling OTC {category} April" type queries
   - Cross-reference against our data
   - Surface new candidates that aren't in our signal feeds

6. **Rank top 5-10 candidates**
   - Score × urgency × confidence
   - Filter out blocked / watched-pause

7. **For each pick, produce a briefing**
   - Title (one line)
   - Summary (2-3 sentences — the "why now")
   - Rationale (full reasoning trail)
   - Confidence 0-1
   - Urgency 1-5
   - Proposed action: `{ kind: 'list', product_id, price, platform: 'amazon' }`
   - Data snapshot + reasoning trail for replay

8. **Insert into `briefings` table**, source_agent = 'research_analyst'
9. **Also insert into `inbox_items`** with state = 'pending' for Chief of Staff to curate

## Output format
Final result written to `result.json`:
```json
{
  "category_group": "allergy",
  "briefings_created": [ "uuid", "uuid", ... ],
  "picks_summary": [
    { "title": "...", "urgency": 4, "confidence": 0.82 }
  ],
  "signals_used": [...],
  "memories_retrieved": [...],
  "runtime_seconds": 42
}
```

## Tool access
Full Claude Code tool access available: Read, Write, Bash, WebSearch (for the Perplexity-style queries), plus Supabase access via environment variables.
```

Other skill files follow this structure — inputs, process, output format, tools. Each references the same policy filter, same memory schema, same briefing format.

## Error Handling Strategy

- **Supabase failures**: Retry only on transient errors (connection timeouts, 503 from PostgREST). Use `p-retry` with `shouldRetry: (err) => err.code === 'PGRST503' || err.code === '57P03' || /timeout|ECONNRESET/i.test(err.message)`. Never retry constraint violations (`23*` codes), invalid SQL (`42*`), or permission errors — those fail fast. Max 2 retries, 500ms + 1500ms backoff.
- **Claude API failures**: Retry on 429, 503, 529, and `overloaded_error`. Never retry 400 (invalid request), 401 (auth), 422 (validation). Use exponential backoff (1s, 3s, 9s), max 3 attempts. If still failing, return 503 to client with friendly error.
- **Voyage embeddings**: Deferred to Phase 1.5 — no embedding calls in Phase 1, so no failure surface.
- **Tool handler errors**: Wrapped in try/catch at the dispatcher, returns `JSON.stringify({ error: message })` to Claude. Claude summarizes gracefully to Kaleem. Tool handlers themselves also catch and return — never let an exception escape the handler.
- **Prompt caching miss**: Happens on first request of a 5-min window. Just more expensive, not broken. No special handling.
- **Streaming client disconnects**: Server-side, catch `controller.enqueue` failures in the ReadableStream, break the loop cleanly.
- **Auth failures**: Return 401 immediately; don't call Anthropic or Supabase.
- **Rate-limit exceeded**: Return 429 with `Retry-After` header. Don't call Anthropic.
- **Token budget exceeded mid-conversation**: Send `error` event on the stream, close.
- **Max tool-iterations exceeded**: Send `error` event on the stream, close. Log the conversation for debugging — this usually means Claude is stuck in a loop or a tool is returning garbage.
- **Secret hygiene**: `SUPABASE_SERVICE_ROLE_KEY` never logged. `lib/logger.ts` redacts any string containing `sk-`, `eyJ`, or matching keys from `REDACT_ENV` env list. `lib/supabase/server.ts` throws at import if `typeof window !== 'undefined'`.
